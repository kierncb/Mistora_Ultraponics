# Mistora Ultraponics

>A compact React + Vite dashboard for monitoring sensor data and controlling thresholds for an Ultraponics system.

Live demo
---------

Vercel deployment: [mistora-ultraponics](https://mistora-ultraponics.vercel.app/)


Features
--------
- Real-time sensor overview and trend charts
- Threshold management and control panel
- Firebase integration for sensor writes and secure rules
- Lightweight Vite + React front-end
